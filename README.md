# Absolute Java Exercises

Solutions to selected programming exercises from *Absolute Java, 6th Edition* by Walter Savitch.

The repository contains my solutions to exercises from Chapters 1–10, written while practicing Java programming fundamentals and object-oriented programming.

## Topics Covered

The exercises cover fundamental Java concepts including:

- Variables and data types
- Input and output
- Conditional statements
- Loops
- Methods
- Arrays
- Strings
- Classes and objects
- Object-oriented programming
- Inheritance and polymorphism
- Exception handling
- Basic data structures
